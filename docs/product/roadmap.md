# Roadmap

The detailed backlog lives in GitHub Issues/Projects. This document records only major product milestones.

## v0.1 — Foundation

Authentication, organisations, roles, core event/venue models and customer event browsing.

## v0.2 — Inventory

Seat layouts, ticket types, session inventory, reservation API, transaction locking, expiry worker and concurrency tests.

## v0.3 — Commerce

Orders, server-side pricing, Stripe Checkout, webhook verification/idempotency, payment state and ticket generation.

## v0.4 — Admission and communication

Ticket wallet, QR/validation flow, Resend transactional email and organiser attendee tooling.

## v0.5 — Realtime and discovery

Redis coordination/pub-sub, real-time seat updates, Typesense indexing/search and S3 media.

## v0.6 — Operations

Refunds, audit logs, organiser analytics, OpenTelemetry instrumentation, security hardening and failure handling.

## v1.0 — Production-style release

AWS deployment, CI/CD, E2E/concurrency/load testing, measured performance report, operational documentation and polished public demo.
